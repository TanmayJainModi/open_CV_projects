# Open_CV_projects
A collection of interactive computer vision applications built with OpenCV, MediaPipe, and PyAutoGUI. These projects demonstrate various ways to interact with your computer using visual inputs like facial features, hand gestures, and more.

# This repository contains several mini-projects exploring different aspects of computer vision:

1.Eye Mouse Control: Control your mouse cursor using eye movements

2.Hand Mouse Control: Use hand gestures to control your cursor and click

3.Smile Detection: Take a selfie automatically when you smile

4.Volume Control: Adjust system volume using hand gestures

5.Color Picker: Interactive RGB color selection tool

6.Face Landmark Detection: Identify and map facial landmarks

7.Pose Estimator: Identify and map body landmarks
